# papers-site

PDFs served at https://papers.jonathandries.com (GitHub Pages), linked from www.jonathandries.com (Google Sites).
Drive links are blocked at many central banks; these links are not.

To update a paper: overwrite the PDF with the **same file name**, then

    git add -A && git commit -m "Update JMP" && git push

The link stays the same and serves the new version within a minute or two.
